# Regla de Control de Versiones (Git)

- **No hacer commits automáticos ni `git push`**: No ejecutes comandos de `git commit` ni `git push` de forma automática tras completar tareas o cambios.
- **Gestión manual por parte del usuario**: El usuario subirá los cambios manualmente cuando lo considere oportuno.
- **Excepción**: Solo ejecuta comandos de Git si el usuario lo solicita explícitamente en su mensaje.
